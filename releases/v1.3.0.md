# ParkBot 1.3.0

## What's new

An update behind the scenes: ParkBot now uses Kotlin. Your familiar screens, selected contacts, themes, and parking schedules stay the same.

Whole-minute SMS timing and the fix for repeated parking-end notifications are included.

## Install

Download **ParkBot-1.3.0.apk** and open it on an Android 8.0 or newer phone. Install it over your previous release to keep settings and history; it must be signed with the same release key.

Always check your parking service's confirmation. SMS and parking charges may apply.
