# ParkBot 1.2.2

Parking renewals by SMS, with your own recipient, message, start/stop times, and interval.

## What's new

- Added signed release builds with debugging disabled.
- Added automatic GitHub release publishing with the APK and a download checksum.
- Kept the existing parking features, themes, and whole-minute scheduling.

## Install

Download **ParkBot-1.2.2.apk** and open it on an Android 8.0 or newer phone.

This release uses the project's permanent release signing key. If you previously installed a debug-signed version, uninstall that version first; this clears its settings and history. Later versions signed with the same release key can update normally.

Allow SMS and Phone access and Alarms & reminders when prompted. Always check the parking provider's confirmation. SMS and parking charges may apply.
