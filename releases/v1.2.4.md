# ParkBot 1.2.4

## What's new

Parking-end notifications now appear once when your session actually ends. Opening ParkBot again or restarting your phone will no longer bring back a notification for a session that already ended.

An active session still resumes its checks after a restart. If it ends during that check, you receive its notification once.

## Install

Download **ParkBot-1.2.4.apk** and open it on an Android 8.0 or newer phone. It updates an existing release installation when signed with the same release key.

Always check your parking service's confirmation. SMS and parking charges may apply.
