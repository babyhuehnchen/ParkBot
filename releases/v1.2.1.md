# ParkBot 1.2.1

Parking renewals by SMS, with your own recipient, message, start/stop times, and interval.

## Features

- Choose a contact or enter a parking short code.
- Choose the sending SIM directly on the main screen.
- Start on the next full minute or at a selected start time; stop automatically.
- Choose an interval of 1–1440 minutes, with no preset interval.
- Renewals ignore seconds: sent at 14:00:59 with a 1-minute interval means the next scheduled SMS is 14:01:00.
- Material 3 controls, SMS history, and session status.
- Light, Dark, and Follow System Settings modes.
- Separate OLED Dark and Material 3 switches. Material 3 controls its own backgrounds and takes priority over OLED.
- White and neutral dark-grey standard palettes.
- Start now hides the start-time box and centers the stop-time box.

## Install

Download **ParkBot-1.2.1-debug.apk** from the release assets and install it on Android 8.0 or newer. Allow installation from the app used to open the APK if Android prompts.

This is a **debug-signed build for testing**, using the same signing certificate as the previously supplied ParkBot builds. It can update those installations without clearing their data. It is not a production-signed or Google Play build. GitHub Actions debug artifacts use a different key and cannot update this local build in place.

Package: tf.dodoapps.parkbot · version code: 7.

## Notes

Grant SMS and Phone permissions and allow Alarms & reminders. Notifications are optional. Check the parking provider confirmation separately: phone-reported sending does not confirm a valid ticket. Android battery restrictions and the carrier may delay actual sending.

The app has no Internet or SMS inbox permission. Form values, session state, and history stay on the device.

Build and 48 scheduler checks passed; Android lint has no errors. The owner confirmed the app and theming work on their phone. The wider device checklist has not been completed.
